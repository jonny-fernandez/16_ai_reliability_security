# Evaluation Matrix

| Dimension | Example metric |
|---|---|
| Task correctness | success rate |
| Grounding | unsupported claim rate |
| Authorization | unauthorized-action rate |
| Security | security violation rate |
| Reliability | recovery success rate |
| Latency | P50/P95/P99 |
| Cost | cost per successful task |
| Load | throughput/error rate |
| Regression | delta vs approved baseline |
